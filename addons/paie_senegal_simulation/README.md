# Paie Sénégal Simulation

Module Odoo 19 indépendant pour simuler un salaire net.

Le module ne dépend d'aucun module RH, contrat ou paie. Il dépend uniquement de base.

Éléments simulés :

- Salaire de base
- Sursalaire
- IR
- TRIMF
- IPRES RG
- IPRES RC
- Transport fixe de 26 000 FCFA

Le salaire net saisi est le salaire net hors transport. Le transport est ensuite ajouté au net à payer.

Les catégories A1 à D2 sont créées par défaut. Les montants de salaire de base sont à renseigner avec la grille retenue par l'entreprise, car aucun montant universel de ces catégories n'a été fourni.
