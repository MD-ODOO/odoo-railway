# Kiiraaye Governance V4 — Odoo 19 Community

V4 : dashboard OWL territorial, métadonnées géographiques (latitude/longitude/GeoJSON), KPI de pilotage, campagnes historiques agrégées, rapport QWeb, cartes de membre 85x54mm avec QR code et logo de la société en filigrane.

Pour afficher le logo Kiiraaye dans la carte, renseigner le logo de la société dans Odoo (`res.company.logo`).

Mise à jour : `./odoo-bin -d votre_base -u kiiraaye_governance --stop-after-init`
