# Imobilier SN

Module Odoo 19 de gestion immobilière pour le Sénégal.

## Gestion des biens

Types supportés :
- Appartement
- Maison entière
- Magasin
- Terrain

Les références sont générées automatiquement selon le type, le propriétaire, la localisation et un numéro séquentiel.

## Contrats

Deux types :
- Location
- Achat / Vente

La location gère la caution, les mois d'avance, le loyer et les échéances.
La vente gère l'acompte et les échéances selon une périodicité mensuelle, trimestrielle, semestrielle ou annuelle.

## Courtage

Un courtier est un contact Odoo marqué comme courtier immobilier. Il possède un pourcentage de commission et peut recevoir n'importe quel type de bien.

## Locataires

Le dossier locataire permet de saisir la situation sociale, la profession, la source de revenu et les justificatifs.

## États des lieux

Les états des lieux avant et après location sont gérés sur le contrat, avec compteurs, clés, constat et pièce jointe.
