Why buyers choose it

A polished login experience managed from Odoo

The login page is often the first screen employees, customers, vendors, and portal users see. This module lets you align that screen with your brand without custom controller work or fragile template overrides.

No-code control

Manage brand text, logo, favicon, colours, typography, form labels, footer links, and announcements from standard Odoo forms.

Real background support

Use solid colours, gradients, animated gradients, uploaded images, or external image URLs with cover, repeat, overlay, blur, brightness, and saturation controls.

Preview before publish

Open a dedicated preview page to inspect the login card across desktop and tablet dimensions before applying the theme to the public login page.

Authentication stays native

The module styles Odoo's login, signup, and reset templates. It does not replace Odoo's authentication controllers or password handling.

Built for admins

A focused theme editor without unnecessary import or export workflows

Login Theme Studio keeps the daily workflow simple: create a theme, adjust the visible tabs, preview it, publish it, and assign it to the selected website. Advanced resolver fields stay internal so normal users see only the controls they need.

  • Branding: company name, page title, heading, subheading, and welcome text.
  • Visual design: logo, layout, colours, typography, card, and background settings.
  • Authentication text: field labels, placeholders, button text, and link labels.
  • Footer: support details, privacy, terms, help, copyright, and powered-by links.
Feature set

Everything included

The module focuses on production-ready login branding: clear settings, safe rendering, preview, and direct control over the public authentication pages.

Branding tab

Set company name, browser title, heading, subheading, welcome message, and visibility toggles for company and footer content.

Logo and favicon

Upload a logo and favicon or use external URLs. Control logo width, height, and alignment directly from the form.

Layout and card styling

Choose the page layout, form width, alignment, padding, card radius, border, shadow, opacity, and blur.

Colour selector

Use a native colour picker for hex colours while still supporting typed CSS colour values such as rgba for overlays.

Typography controls

Select common font families and configure heading, body, and button font sizing for a consistent login experience.

Background image rendering

Uploaded background images are served through a public theme-safe route and rendered on both preview and live login pages.

Form labels and options

Edit username and password labels, placeholders, login button text, sign-up text, reset text, password toggle, OAuth visibility, and autofocus behavior.

Footer and legal links

Show support email, phone, support URL, privacy, terms, help, copyright, and powered-by links below the login form.

Announcements

Display a formatted information, success, warning, maintenance, or security message above the login fields.

Field help on hover

Every visible theme field includes help text so administrators can understand each option without leaving the form.

Website theme setting

Choose the login theme from Website settings for each website. Leave the field empty to use Odoo's native login page.

Safe public payload

Only safe theme values are exposed to public authentication pages, with URL validation and native login fallback on rendering errors.

How to use

Publish a branded login page in minutes

1. Create theme

Open Website > Configuration > Settings and use the Login Theme section to create or select a website login theme.

2. Configure tabs

Set branding, logo, layout, colours, typography, background, form, footer, and announcement options.

3. Preview

Use the Preview button to review draft changes before users see them.

4. Publish

Publish the theme and select it in the Website Login Theme setting for the target website.

FAQ

Common questions

Does this replace Odoo authentication?

No. It styles Odoo's existing authentication templates and keeps the native login, signup, reset password, OAuth, and security behavior intact.

Where does the background image appear?

The background image appears behind the login card on the preview frame and on the live Odoo login page after the theme is published and selected for the current website.

Can I temporarily disable the custom login page?

Yes. Leave the Website Login Theme field empty for that website to render Odoo's native authentication pages without uninstalling the module.

Do I get support?
